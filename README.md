## Featured portfolio

### 1. 🚕 Uber Fare Prediction — End-to-End Machine Learning
[**Repository**](https://github.com/mightyalok00/Uber-Fare-Prediction-Model) • [**Live Streamlit App**](https://uber-fare-prediction-model.streamlit.app/)
